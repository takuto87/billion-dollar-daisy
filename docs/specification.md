# Billion Dollar Daisy - 投資管理AIアシスタントツール 詳細仕様書

本ドキュメントは、投資管理およびAI補助ツール「Billion Dollar Daisy」のシステム仕様およびUI/UX設計を管理するための仕様書です。

---

## 1. プロジェクト概要 & コンセプト

### コンセプト：冷静な意思決定をAIが支える「投資のパーソナルコーチ」
多くの個人投資家が、感情（恐怖や強欲）によって当初の計画（シナリオ）を破り、損失を膨らませてしまいます。
本システムは、以下の3つの原則を徹底させることで、投資のパフォーマンスを最大化することを目指します。

1.  **理念の遵守（Constitution）**: 取引前にマインドセットを整える。
2.  **シナリオの強制（Screening）**: エントリー・ロスカット・利益確定のシナリオなしでの取引を禁止する。
3.  **タイムライン駆動（Assets）**: 日常の監視タスクをタイムラインで整理し、今日やるべきことだけに集中する。
4.  **冷徹な振り返り（Review）**: シーズン（期間）ごとに計画と実績をAIが客観的に対比・分析する。

## 2. データモデル設計（外部DB接続想定）

将来的にデータベース（Firebase FirestoreやPostgreSQL等）に保存することを前提とした、論理データモデルです。

### 2.1. Season（シーズン）
投資を特定の期間（例：四半期、1ヶ月など）で区切り、資金管理を行う単位。
```typescript
interface Season {
  id: string;          // シーズンID (UUID)
  name: string;        // シーズン名 (例: "2026年Q2")
  startDate: string;   // 開始日 (YYYY-MM-DD)
  endDate: string;     // 終了日 (YYYY-MM-DD)
  budget: number;      // 投資予算 (総資金)
  status: 'active' | 'archived'; // ステータス
  createdAt: string;
}
```

### 2.2. Asset（アセット/投資銘柄）
スクリーニングにより決定した、監視および投資対象の銘柄。
```typescript
interface Asset {
  id: string;
  seasonId: string;    // 所属するシーズンID
  code: string;        // 銘柄コード / ティッカー (例: "7203", "AAPL")
  name: string;        // 銘柄名
  targetRatio: number; // 目標構成比率 (%)
  status: 'watching' | 'holding' | 'closed'; // 状態 (監視中/保有中/終了)
  
  // 3大シナリオ
  entryScenario: string;     // エントリー（購入）シナリオ
  lossCutScenario: string;   // ロスカット（損切り）シナリオ
  takeProfitScenario: string;// テイクプロフィット（利確）シナリオ
  
  // 目標値・限界値
  entryPrice: number;        // 想定エントリー価格
  lossCutPrice: number;      // 想定ロスカット価格
  takeProfitPrice: number;   // 想定テイクプロフィット価格
  
  // 実際の実績（クローズ時に記録）
  actualEntryPrice?: number;
  actualExitPrice?: number;
  actualExitDate?: string;
  pnl?: number;              // 実現損益
  exitReason?: 'profit' | 'loss' | 'manual'; // クローズ理由
  
  createdAt: string;
}
```

### 2.3. TimelineEvent（タイムライン・タスク）
各アセットに紐づく、スケジュールまたは監視用のイベント。
```typescript
interface TimelineEvent {
  id: string;
  assetId: string;     // 紐づくアセットID
  title: string;       // イベント・タスク内容 (例: "第1四半期決算発表")
  date: string;        // 予定日 (YYYY-MM-DD)
  type: 'earnings' | 'macro' | 'price_alert' | 'todo'; // 分類
  status: 'pending' | 'completed'; // ステータス
  description?: string; // 詳細情報やAIからのメモ
  createdAt: string;
}
```

### 2.4. MindsetLog（マインドセット自己診断ログ）
日々の精神状態と、それに対するAIのアドバイス履歴。
```typescript
interface MindsetLog {
  id: string;
  date: string;        // 記録日 (YYYY-MM-DD)
  feeling: string;     // ユーザーの入力（現在の気分・市場への所感）
  stressLevel: number; // ストレス・焦り度 (1〜5)
  aiAdvice: string;    // AIから提示された格言やアドバイス
  createdAt: string;
}
```

## 3. 画面詳細仕様 & UIレイアウト設計案

### 3.1. Constitution（理念・マインドセット）
*   **目的**: 取引前の自己対話と理念の再確認。
*   **画面UI構成**:
    *   **憲章カードデッキ**: 「1. 損失は計画の一部である」「2. シナリオ外の取引は悪である」といった投資理念を、美しいグラデーションとタイポグラフィのカードで表示。カードをスワイプやクリックでめくる演出。
    *   **自己診断セクション**:
        *   「現在の気分（焦り、恐怖、強欲、冷静など）」を5段階の絵文字で入力。
        *   フリーテキストで「今感じていること（例：周りが儲かっていて焦る、等）」を入力するフォーム。
        *   「理念を確認して取引へ臨む」ボタン。
    *   **AIフィードバックエリア**:
        *   診断送信後、入力された感情に対してAIが投資憲章に即したパーソナライズ格言・助言を生成。
        *   ガラスモーフィズムの美しいコンテナ内にタイピングアニメーションで表示。

### 3.2. Screening（スクリーニング & シナリオ策定）
*   **目的**: 贅沢なAIディープリサーチを基に、感情に左右されない強固な投資シナリオを策定し、シーズン計画に組み込む。
*   **画面UI構成とワークフロー (3フェーズ形式)**:
    *   **【フェーズ1: 銘柄指定とAIディープリサーチ】**
        *   **入力項目**: 銘柄コード / ティッカー、市場（日本/米国など）。
        *   **ディープリサーチ実行**: 「AIディープリサーチを実行」ボタンを押すと、AIがインターネット検索や過去の財務・ニュース等のデータを徹底的に分析する演出アニメーション（「データスキャン中...」「センチメント分析中...」等）が走る。
        *   **リサーチレポート出力**:
            *   *市場環境 & 競合ポジショニング*: 業界内での立ち位置やSWOT分析。
            *   *ファンダメンタルズ診断*: PER, PBR, ROE, 成長率などのスコアリング。
            *   *センチメント分析*: 直近のニュースやSNS、フォーラム等からの感情分析（ポジティブ/ネガティブの比率）。
            *   *テクニカル水準*: 主要なサポート/レジスタンスライン、ボラティリティ（ATR：アベレージ・トゥルー・レンジ）。
            *   *重要イベント*: 直近の決算発表日、製品ローンチ、マクロ経済の重要指標発表スケジュール。
    *   **【フェーズ2: シナリオプランニング（AIアシスト付き）】**
        *   ユーザーはリサーチ結果を横に見ながら、エントリー、ロスカット、テイクプロフィットの3大シナリオを構築。
        *   **AI推奨値の提示**: テクニカル分析とボラティリティを基に、AIが推奨するエントリー価格・ロスカット価格（例：ATRの2倍下に設定等）・利確目標価格を自動計算して提示。
        *   **シナリオ記述エリア**:
            *   *エントリーシナリオ*: なぜここで買うのか（ファンダメンタルズ／テクニカルの根拠）。
            *   *ロスカットシナリオ*: なぜここで切るのか（シナリオが崩れる論理的ライン）。
            *   *テイクプロフィットシナリオ*: どこまで狙うのか（目標の妥当性）。
    *   **【フェーズ3: シナリオ最終診断 & 承認】**
        *   「シナリオを最終診断する」ボタンで、AIが入力された文章のロジックやリスクリワード比（利幅/リスク幅）を厳格に評価。
        *   AIから合格（APPROVE）または警告（WARN - 理由付き）のフィードバックが提示される。
        *   納得したら「アセットとして承認・追加」をクリック。
        *   追加時に、フェーズ1で検出された「重要イベント（決算日等）」が**Assetsのタイムラインに自動的にインポート**される。


### 3.3. Assets（構成比アセット一覧 & タイムライン）
*   **目的**: 今日のタスクと全体のバランスを一目で把握し、実行に移す。
*   **画面UI構成**:
    *   **左右３カラムまたはスプリットレイアウト**:
        *   **左エリア（構成比アセットリスト）**:
            *   アセットが構成比順（％）に縦並び。
            *   カードのデザイン：
                *   `Watching`（未購入）: 半透明のグラスモーフィズム。枠線は細く、文字は少しトーンダウン。
                *   `Holding`（購入済）: 実体化。ネオン調の枠線（上昇時はSuccessグリーン、下落時はDangerレッドの微細なグラデーション）、価格や評価損益が鮮明に表示。
                *   カード内のトグルスイッチで「Watching ⇄ Holding」をワンタップで切り替え。
        *   **中央/右エリア（タイムライン ＆ タスク）**:
            *   **タイムライン（縦スクロールのスレッド形式）**:
                *   「今日 ⇄ 明日 ⇄ 今週」と続くスケジュールライン。
                *   各銘柄に紐づくイベント（例：銘柄A決算、銘柄Bが損切り価格に接近、など）がタイムライン上にバブルとして配置される。
                *   AIが「シナリオから判断した本日の監視ポイント」をタイムラインに自動挿入。
            *   **ToDoリスト**:
                *   「今日自分がチェックすべきこと」がチェックボックス付きで上部に固定表示。（例：「☑︎ AAPLのサポートライン反発を確認する」「☐ TSLAの決算説明会資料を読む」など）。

### 3.4. Review（シーズン振り返り）
*   **目的**: トレード結果からバイアスを抜き出し、投資行動のクセを改善する。
*   **画面UI構成**:
    *   **シーズン選択**: 過去のシーズン（例：2026年Q1）をドロップダウンで選択。
    *   **アセット実績リスト**:
        *   結果（利確 / 損切り / 途中クローズ）、損益額、損益率。
        *   「当初シナリオを何％遵守できたか」のユーザー自己評価。
    *   **AIバイアス自己分析**:
        *   「振り返りレポートを生成」ボタン。
        *   AIが、計画時点のシナリオ（期待値）と実際の結果（クローズ理由、損益）を比較分析。
        *   「プロスペクト理論（利小損大）の罠に落ちていませんでしたか？」「利益確定を焦る『早すぎる利確』の兆候があります」などの、バイアス特定と対策レポートを生成。

### 4.1. Screening（スクリーニング）画面のAI定義

#### 4.1.1. ディープリサーチAI（フェーズ1）
*   **システムプロンプト**:
    *   「あなたは世界最高峰のプロフェッショナル投資リサーチAIです。指定された銘柄コードについて、インターネット上の財務情報、センチメント（ニュースやSNSでの感情極性）、業界トレンド、ボラティリティから算出したテクニカル水準、および今後控える重要イベントを網羅的に分析し、ユーザーが投資シナリオを組み立てるための客観的かつ深いレポートを作成してください。」
*   **インプット**:
    *   銘柄コード/ティッカー、対象市場。
*   **アウトプット（JSON想定）**:

#### 4.1.2. シナリオ診断AI（フェーズ3）
*   **システムプロンプト**:
    *   「あなたは冷徹かつ合理的なシニア投資アナリスト兼リスク管理者です。ユーザーが提案した投資アセットの3大シナリオ（エントリー・ロスカット・テイクプロフィット）と数値設定（目標価格）を、フェーズ1で得られたディープリサーチ結果と突き合わせて批判的に検証し、論理的破綻やリスクリワード比の歪みがないかを診断してください。」
*   **インプット**:
    *   銘柄情報（ディープリサーチ結果を含む）
    *   ユーザーの設定価格（エントリー、ロスカット、利確）

*   **アウトプット（JSON想定）**:
    ```json
    {
      "riskRewardRatio": 2.5,        // 利幅/リスク幅の比率

      "verdict": "APPROVE" | "WARN", // 判定
      "analysis": {
        "logicCheck": "エントリー根拠と損切りラインの整合性は取れていますが、利確目標が過去最高値を上回っており、達成難易度が高い可能性があります。",

      },
      "suggestedEvents": [           // タイムラインに追加で登録すべき推奨イベント（価格アラート等）
        { "title": "想定ロスカットライン到達の監視", "offsetDays": 0, "type": "price_alert" },
        { "title": "直近決算日の確認とシナリオ再評価", "offsetDays": 7, "type": "earnings" }

    }
    ```

### 4.2. マインドセットAI (Constitution画面)
*   **システムプロンプト**:
    *   「あなたは投資哲学の大家（マーク・ダグラスやベンジャミン・グレアム）の思想を持つAIコーチです。市場に対する恐怖や強欲、焦りを感じている投資家に対し、冷静さを取り戻し、自己のルールを守るための深い格言とアドバイスを150字以内で提示してください。」
*   **インプット**:
    *   感情（焦り/怒り/喜び/恐怖等）、現在の心理テキスト。
*   **アウトプット**:
    *   アドバイステキスト、引用格言。

### 4.3. 振り返りAI (Review画面)
*   **システムプロンプト**:
    *   「あなたは行動経済学と投資家心理の専門家です。ユーザーの計画時のシナリオと、実際のトレード結果（損益、撤退理由、自己評価）を分析し、ユーザーが陥りやすい認知バイアスを浮き彫りにし、次回の改善アクションを提示してください。」
*   **インプット**:
    *   アセットごとの（計画シナリオ ＋ 実際の結果 ＋ 反省点テキスト）の配列。
*   **アウトプット（JSON想定）**:
    ```json

      "scoreCard": {
    ```
